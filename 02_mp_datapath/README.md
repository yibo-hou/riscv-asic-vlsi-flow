# MP Datapath

This milestone contains the custom datapath implementation, checkpoint screenshots, and public-safe validation summaries. In addition to the required bit-sliced datapath, it includes a **datapath-with-shifter extra-credit variant**.

- `checkpoint1_results/`: ALU, register-file, and early datapath validation artifacts.
- `checkpoint2_results/`: final datapath screenshots and validation summary, including `datapath_with_shift_*` extra-credit schematic and layout artifacts.

The milestone was integrated and verified using course-provided reference infrastructure, which is intentionally not redistributed here.

Raw course release documents, private grading records, full EDA-tool logs, and course-provided reference code are not included.
